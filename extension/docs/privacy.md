# Privacy policy: shall-not-pass browser extension

*Last updated: November 2026*

The shall-not-pass browser extension collects nothing, stores nothing, and sends nothing.

- **What it reads:** on `www.youtube.com` and `open.spotify.com` only, it checks whether the page is showing an interruption. That check happens inside your browser.
- **What it changes:** whether that tab is muted.
- **What it keeps:** nothing. It has no storage, no analytics, and no account.
- **What it sends:** nothing. It never connects to any server, including ours.
- **Other sites:** it doesn't run on any other site, and it can't see your browsing history or the addresses of your tabs.

The code is open source: [github.com/andrewgwoodruff/shall-not-pass](https://github.com/andrewgwoodruff/shall-not-pass/tree/main/extension).

Questions: [open an issue](https://github.com/andrewgwoodruff/shall-not-pass/issues/new/choose).
